# 构建与打包 · 爱弥斯 · 环境检测

> 目标产物：**一个 `爱弥斯·环境检测.exe`，双击即用，无安装器、无注册表、无外部 DLL。**
> 本机已验证工具链：Windows 11 26100 / Node 24.12 / Rust 1.99.1 / MSVC 14.39 / Windows SDK 10.0.22621 / WebView2 155。

---

## 1. 依赖前置

| 依赖 | 用途 | 本机位置 / 获取 |
|---|---|---|
| Node 18+ | 前端构建、Tauri CLI | `D:\nodejs\node.exe`（24.12） |
| Rust stable (msvc) | 编译 Tauri 核心 | `%USERPROFILE%\.cargo\bin` |
| MSVC 生成工具 | Rust 链接器 | `VS 2022 Community` 的 MSVC 14.39 |
| Windows SDK | 链接 Windows API | `D:\Windows Kits\10\`（10.0.22621） |
| WebView2 Runtime | 运行时渲染（目标机需要有） | Win11 自带；Win10 随 Edge 装 |

> Rust 装法（本机已装）：`rustup-init.exe -y --default-toolchain stable-x86_64-pc-windows-msvc --profile minimal --no-modify-path`
> 国内加速：`~/.cargo/config.toml` 里把 crates-io replace 成 `sparse+https://rsproxy.cn/index/`。

## 2. 一条命令出包

```powershell
# 在 D:\zm\hjjc 下
pwsh -File scripts\build-portable.ps1
```

它会依次做：

1. `npm run app:build` → `vite build` + `cargo build --release`（`tauri build --no-bundle`，**不出安装器**）
2. 从 `src-tauri/target/release/` 找出 exe，拷到 `release/爱弥斯·环境检测.exe`
3. 生成 `release/使用说明.txt`（含 SHA256、体积、构建时间）
4. 压缩成 `release/爱弥斯环境检测-v1.0.0-绿色版.zip`

可选参数：

```powershell
pwsh -File scripts\build-portable.ps1 -Clean      # 全量重编（清理 target，约 5-10 分钟）
pwsh -File scripts\build-portable.ps1 -SkipBuild  # 只重新收集/打包（调流水线用）
```

## 3. 分步命令（排查用）

```powershell

npm run app:build

# 4) 产物

```

## 4. 产物为什么这么小

Tauri 不打包浏览器内核，运行时用**系统自带的 WebView2**。所以：

- 前端产物（JS/CSS/字体）全被塞进 exe 的二进制资源里，不落地散文件
- `[profile.release]`：`lto = true`、`codegen-units = 1`、`panic = "abort"`、`strip = true`、`opt-level = 3`
- **字体做了子集化**（关键的一步，省了 11.9MB）：
  `@fontsource` 的 CJK 字体是按 unicode-range 切成 174 个子集的，整包 12.3MB；
  本应用真正用到的字符只有 2362 个（其中汉字 691 个）。
  `scripts/subset-fonts.py` 用 fontTools 把「站酷小薇 + 马善政」裁到只剩用到的字符 →
  两套字体 **4788KB → 542KB**。

实测体积（2026-10-18，本机）：

| 阶段 | exe 体积 |
|---|---|
| 字体未优化（@fontsource 整包） | 17.72 MB |
| 字体子集化后 | **5.86 MB** |
| zip 压缩包（exe + 使用说明） | 2.81 MB |

拆解：Rust + Tauri 本体 ≈ 5.1MB 里其实含前端资源；前端 dist 从 13MB 降到 1.01MB
（JS 430KB / CSS 45KB / 字体 542KB），其余是 Rust 运行时。

> 改了界面文案之后要重跑一次字体子集（否则新出现的字可能落到系统字体兜底）：
> ```powershell
> python scripts/subset-fonts.py
> ```
> 脚本会自动扫描 `src/**/*.tsx`、`src/**/*.ts`、`index.html`、`dev/texts.json` 里用到的全部字符。

> 如果哪天体积突然涨到十几 MB，先查两件事：
> ① 有没有把 `@fontsource` 整包又 import 回来（`main.tsx` 里不应该再有 `import "@fontsource/..."`）；
> ② `tauri.conf.json` 的 `bundle.active` 是不是被改成 true 了（那会去拉 NSIS/WiX 打包工具）。

## 6. 目标机要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 1809+ / Windows 11，**64 位** |
| WebView2 | 需要。Win11 自带；Win10 一般随 Edge/Office 装过 |
| 权限 | 普通用户可跑；温度/SMART/TPM 需要管理员（界面有「以管理员重启」） |
| 运行库 | 无（Rust 静态链接了 CRT，不需要 VC++ Redist） |

> 如果目标机真的没有 WebView2，程序会启动失败。兜底方案：随包附一个 `WebView2Setup.exe`（微软官方 evergreen bootstrapper，约 1.8MB），
> 在 README/使用说明里写明。首版先不加，等真遇到再说。

## 7. 常见问题

| 现象 | 原因 / 解法 |
|---|---|
| `cargo` 找不到 | PATH 里加 `%USERPROFILE%\.cargo\bin`，或重开终端 |
| 链接报 `link.exe not found` | MSVC 生成工具没装，或 Windows SDK 缺失（`vswhere -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64`） |
| `error: linker link.exe not found` | 同上；Rust 需要 MSVC 的 link.exe 在 PATH 或能被 cc-rs 找到 |
| crates 下载卡住 | 检查 `~/.cargo/config.toml` 的 rsproxy 镜像；`cargo` 不要用 `search`（镜像不支持） |
| 前端报字体 404 | 检查 `src/assets/fonts/*.woff2` 是否存在；不在就先跑 `python scripts/subset-fonts.py` |
| 界面里部分汉字变成系统字体 | 字体子集没覆盖那个字（改了文案没重跑子集脚本），重跑 `python scripts/subset-fonts.py` 再构建 |
| 截图里界面是白的 | 多半是 `WebView2` 没起来，或 `frontendDist` 路径不对（应为 `../dist`） |
| 杀软误报 | 未签名的 Rust 二进制偶发误报；可自行编译或加白 |

## 9. 版本号改哪里

三处必须同步：

1. `package.json` → `version`
2. `src-tauri/Cargo.toml` → `[package] version`
3. `src-tauri/tauri.conf.json` → `version`

`app_info()` 命令读的是 `CARGO_PKG_VERSION`（即 Cargo.toml），界面页脚显示的也是它。
