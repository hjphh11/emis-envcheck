# 数据契约 · 爱弥斯 · 环境检测

> 前后端并行开发的**唯一接口**。改字段先改 `src/types.ts`，再改这里。
> 三个角色都只认这份契约：采集器(scan.ps1) 产出它 → Rust 透传 → 前端渲染它。

## 0. 一句话架构

```
scan.ps1  ──(JSON)──>  Rust (tauri)  ──(invoke)──>  React 界面
  PowerShell 采集        只做转发/补算/窗口        只管渲染
```

- 采集全部在 PowerShell 里完成（WMI / 注册表 / CIM / 常见目录扫描），输出**一个 JSON**。
- Rust 不重复实现采集逻辑，只负责：调用脚本、把 JSON 反序列化成 `ScanResult`、补 `meta.scanMs`、
  提供实时监控（`sysinfo` 每秒采样）、提权重启、写文件。
- 前端**不做**任何数据计算（评分、兼容性判定都在采集器里算好），只做格式化与展示。

## 1. 字段规范（硬性）

| 项 | 规定 |
|---|---|
| 命名 | camelCase，与 `src/types.ts` 完全一致 |
| 容量 | `number`，单位 **bytes** |
| 频率 | `number`，单位 **MHz** |
| 百分比 | `number`，**0–100**（不是 0–1） |
| 时间 | ISO-8601 本地时间字符串，如 `2026-10-18T19:30:00+08:00` |
| 拿不到 | 对象字段 `null`、数组 `[]`、布尔 `null`（三态）。**禁止** `"N/A"` / `""` / `-1` |
| 编码 | 采集器写出的 JSON 必须是 **UTF-8 无 BOM** |
| 枚举 | `CheckStatus = pass/warn/fail/unknown`；`DiskHealth = healthy/warning/critical/unknown` |

## 2. JSON 顶层结构（= `ScanResult`）

```jsonc
{
  "meta":        { "collectorVersion": "1.0.0", "isAdmin": false, "elevationGains": [], "warnings": [] },
  "system":      { ... },   // 系统 / 激活 / 运行时长 / 整机
  "motherboard": { ... },   // 主板 / BIOS / UEFI / SecureBoot / TPM
  "cpu":         { ... },
  "memory":      { ... },   // 含 modules 内存条明细
  "gpus":        [ ... ],
  "displays":    [ ... ],
  "disks":       [ ... ],   // 物理盘，含 volumes
  "network":     { "adapters": [...], "internet": true, "latencyMs": 23, "dnsOk": true },
  "runtime":     { ... },   // B 页签：.NET / VC++ / DirectX / WebView2 / Java / Node / Python / Git / WSL
  "security":    { ... },
  "compat":      { "verdict": "ok", "passCount": 9, "warnCount": 1, "failCount": 0, "unknownCount": 0, "items": [...] },
  "score":       { "total": 86, "level": "good", "parts": [ ... ] }
}
```

`scan.ps1` 只负责产出到 `score` 为止；`meta.scanMs`、`meta.generatedAt`、`meta.isAdmin`
由 Rust 兜底填（PowerShell 也填，Rust 覆盖为准）。

## 3. Tauri 命令清单（前后端约定，名字不能改）

| 命令 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `scan_all` | — | `ScanResult` | 全量扫描，异步；内部跑 scan.ps1（约 2–6s） |
| `live_snapshot` | — | `LiveSnapshot` | 实时监控单次采样，前端每 1000ms 调一次 |
| `app_info` | — | `AppInfo` | 名称/版本/作者/主页/构建日期 |
| `relaunch_elevated` | — | `void` | 以管理员身份重启自身，成功后旧进程退出 |
| `write_text_file` | `{ path, content }` | `void` | 写报告/JSON 用（前端已选好路径） |
| `open_path` | `{ path }` | `void` | 用系统默认程序打开导出的文件 |
| `open_url` | `{ url }` | `void` | 打开 qingwu.ink / 项目主页 |

> 保存对话框在**前端**用 `@tauri-apps/plugin-dialog` 的 `save()` 弹出，选完路径再调 `write_text_file`。
> 剪贴板用 `@tauri-apps/plugin-clipboard-manager`，不经过 Rust。

## 5. 开发/构建命令

```powershell
# 纯前端预览（浏览器里用 mock 数据，便于截图验收）
npm run dev

# 桌面开发（需要 Rust，路径见下）
npm run app:dev

# 出单文件绿色版 exe（不打包安装器）
npm run app:build     # 产物：src-tauri/target/release/emis-envcheck.exe
```

Rust 工具链在本机：`%USERPROFILE%\.cargo\bin`（需临时加进 PATH）。
构建镜像变量（国内加速，写进脚本里）：
`CARGO_HOME` 默认即可；crates 源用 `~/.cargo/config.toml` 的 `rsproxy` 镜像。

## 6. 验收口径（Lead 会按这个查）

1. `npm run build` 0 error；`cargo check` 0 error。
2. 浏览器 mock 模式四个页签都能渲染，无横向滚动。
3. 真机扫描：`scan_all` 返回的每个顶格 section 都非空，`warnings` 里能说清缺哪项。
4. 导出的 HTML 报告双击能直接在浏览器看，中文不乱码。
5. 打包出的 exe 拷到别的目录双击能跑（WebView2 依赖 Win10/11 自带）。
