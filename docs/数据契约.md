# 数据契约 · 爱弥斯 · 环境检测

> 前后端并行开发的**唯一接口**。改字段先改 `src/types.ts`，再改这里。
> 三个角色都只认这份契约：采集器(scan.ps1) 产出它 → Rust 透传 → 前端渲染它。

## 0. 一句话架构

```
scan.ps1  ──(JSON)──>  Rust (tauri)  ──(invoke)──>  React 界面
  PowerShell 采集        只做转发/补算/窗口        只管渲染
```

- 采集全部在 PowerShell 里完成（WMI / 注册表 / CIM / 常见目录扫描），输出**一个 JSON**。
- Rust 不重复实现采集逻辑，只负责：调用脚本、把 JSON 反序列化成 `ScanResult`、补 `meta.scanMs`、
  提供实时监控（`sysinfo` 每秒采样）、提权重启、写文件。
- 前端**不做**任何数据计算（评分、兼容性判定都在采集器里算好），只做格式化与展示。

## 1. 字段规范（硬性）

| 项 | 规定 |
|---|---|
| 命名 | camelCase，与 `src/types.ts` 完全一致 |
| 容量 | `number`，单位 **bytes** |
| 频率 | `number`，单位 **MHz** |
| 百分比 | `number`，**0–100**（不是 0–1） |
| 时间 | ISO-8601 本地时间字符串，如 `2026-10-18T19:30:00+08:00` |
| 拿不到 | 对象字段 `null`、数组 `[]`、布尔 `null`（三态）。**禁止** `"N/A"` / `""` / `-1` |
| 编码 | 采集器写出的 JSON 必须是 **UTF-8 无 BOM** |
| 枚举 | `CheckStatus = pass/warn/fail/unknown`；`DiskHealth = healthy/warning/critical/unknown` |

## 2. JSON 顶层结构（= `ScanResult`）

```jsonc
{
  "meta":        { "collectorVersion": "1.1.0", "isAdmin": false, "elevationGains": [], "warnings": [] },
  "system":      { ... },   // 系统 / 激活 / 运行时长 / 整机
  "motherboard": { ... },   // 主板 / BIOS / UEFI / SecureBoot / TPM
  "cpu":         { ... },
  "memory":      { ... },   // 含 modules 内存条明细
  "gpus":        [ ... ],
  "displays":    [ ... ],
  "disks":       [ ... ],   // 物理盘，含 volumes
  "network":     { "adapters": [...], "internet": true, "latencyMs": 23, "dnsOk": true },
  "runtime":     { ... },   // B 页签：.NET / VC++ / DirectX / WebView2 / Java / Node / Python / Git / WSL
                             //          + software: SoftwareItem[]（MySQL/Redis/Docker/VS Code… 见 §2.1）
  "security":    { ... },
  "compat":      { "verdict": "ok", "passCount": 9, "warnCount": 1, "failCount": 0, "unknownCount": 0, "items": [...] },
  "score":       { "total": 86, "level": "good", "parts": [ ... ] }
}
```

`scan.ps1` 只负责产出到 `score` 为止；`meta.scanMs`、`meta.generatedAt`、`meta.isAdmin`
由 Rust 兜底填（PowerShell 也填，Rust 覆盖为准）。

### 2.1 已安装软件 `runtime.software[]`（v1.1.0 新增）

「环境」页签的第三方软件检测。**装了什么报什么，没装就跳过，绝不输出占位空项。**

```jsonc
{
  "name": "Docker Desktop",              // 人能看懂的名字，不直接甩注册表 DisplayName
  "version": "4.86.0",                   // 可为 null
  "path": "C:\\Program Files\\Docker\\Docker\\Docker Desktop.exe",  // 可为 null
  "category": "container",               // database | container | webServer | language | devTool | common
  "source": "registry",                  // registry | service | path | command | dir | null
  "running": false,                      // 服务/进程是否在跑；非服务类为 null
  "detail": "客户端 29.7.2"              // 端口、引擎版本、附加说明；可为 null
}
```

检测覆盖面（v1.1.0）：

| category | 检测对象 |
|---|---|
| `database` | MySQL、MariaDB、PostgreSQL、Redis、MongoDB、SQL Server、SQLite |
| `container` | Docker Desktop、Podman、VirtualBox、VMware |
| `webServer` | nginx、Apache、IIS |
| `language` | PHP、Go、Rust、.NET SDK、MSBuild、Android SDK、Ruby、Perl、MinGW |
| `devTool` | Visual Studio、VS Code、JetBrains、Maven、Gradle |
| `common` | Steam、Office、WPS、微信、QQ、网易云音乐、PotPlayer 等 |

> Node / Python / Git / Java 不重复塞进 `software`，它们仍在 `runtime.node` 等专有字段里。
> `types.rs` 对 `software` 用 `#[serde(default)]`，**老采集器不输出该字段时为空数组**，不会导致扫描失败。

### 2.2 兼容性新增项（v1.1.0）

`compat.items[]` 从 15 项扩到 17 项，新增：

| id | 判定 |
|---|---|
| `gpu.driver` | 显卡驱动是否正常安装（版本可读 + WDDM ≥ 2.0）；异常 fail，读不到 unknown |
| `gpu.driverAge` | 驱动日期距今 > 18 个月 → warn（建议更新）；≤ 18 个月 pass；无日期 unknown |

多显卡时以 `discrete === true`（独显）那块为准。

## 3. Tauri 命令清单（前后端约定，名字不能改）

| 命令 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `scan_all` | — | `ScanResult` | 全量扫描，异步；内部跑 scan.ps1（约 2–6s） |
| `live_snapshot` | — | `LiveSnapshot` | 实时监控单次采样，前端每 1000ms 调一次 |
| `app_info` | — | `AppInfo` | 名称/版本/作者/主页/构建日期 |
| `relaunch_elevated` | — | `void` | 以管理员身份重启自身，成功后旧进程退出 |
| `write_text_file` | `{ path, content }` | `void` | 写报告/JSON 用（前端已选好路径） |
| `open_path` | `{ path }` | `void` | 用系统默认程序打开导出的文件 |
| `open_url` | `{ url }` | `void` | 打开 qingwu.ink / 项目主页 |

> 保存对话框在**前端**用 `@tauri-apps/plugin-dialog` 的 `save()` 弹出，选完路径再调 `write_text_file`。
> 剪贴板用 `@tauri-apps/plugin-clipboard-manager`，不经过 Rust。

## 5. 开发/构建命令

```powershell
# 纯前端预览（浏览器里用 mock 数据，便于截图验收）
npm run dev

# 桌面开发（需要 Rust，路径见下）
npm run app:dev

# 出单文件绿色版 exe（不打包安装器）
npm run app:build     # 产物：src-tauri/target/release/hjjc.exe
```

> 注意：exe 名来自 `src-tauri/Cargo.toml` 的 `[package] name`（当前 `hjjc`），
> `scripts/build-portable.ps1` 会把它收集并重命名为 `release/爱弥斯·环境检测.exe`。

Rust 工具链在本机：`%USERPROFILE%\.cargo\bin`（需临时加进 PATH）。
构建镜像变量（国内加速，写进脚本里）：
`CARGO_HOME` 默认即可；crates 源用 `~/.cargo/config.toml` 的 `rsproxy` 镜像。

## 6. 契约自检

```powershell
# 用脱敏后的真实扫描样本校验 863 项契约断言（CI 可跑）
pwsh -NoProfile -File dev\verify.ps1

# 用你自己的真机扫描结果校验
pwsh -NoProfile -File dev\verify.ps1 -Path <scan.json>
```

`dev/sample-scan.json` 是入库的脱敏样本（主机名 / 用户名 / 序列号 / MAC / IP / SSID 均已替换），
采集自一台 i7-14650HX + RTX 4060 的机器，17 项兼容全 pass。改了 `scan.ps1` 的产出结构后要同步更新它。

## 7. 验收口径（Lead 会按这个查）

1. `npm run build` 0 error；`cargo check` 0 error。
2. 浏览器 mock 模式四个页签都能渲染，无横向滚动。
3. 真机扫描：`scan_all` 返回的每个顶格 section 都非空，`warnings` 里能说清缺哪项。
4. 导出的 HTML 报告双击能直接在浏览器看，中文不乱码。
5. 打包出的 exe 拷到别的目录双击能跑（WebView2 依赖 Win10/11 自带）。
6. `dev/verify.ps1` 863 项全过。
7. `scan_all` 在 20s 内必须有结果或明确报错（Rust 侧硬超时）。
